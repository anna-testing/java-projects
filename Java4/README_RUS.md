# Backend игры «Крестики-нолики»: база данных и авторизация

## Цель проекта

Расширить игровой backend хранением данных, авторизацией и поддержкой двух пользователей.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- подключено хранение игровых данных в PostgreSQL;
- реализована авторизация пользователей;
- добавлена логика игры между двумя участниками.

## Использованные инструменты

Java 18, Spring Boot, Spring Data JPA, Spring Security, PostgreSQL, Gradle.

## Полученный результат

В каталоге `src` сохранено: 29 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Настроить подключение PostgreSQL, перейти в `src/tic_tac_toe_T4` и выполнить `./gradlew bootRun`.
