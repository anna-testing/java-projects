# Backend игры «Крестики-нолики»: JWT и статистика

## Цель проекта

Дополнить игровой backend безопасной авторизацией и пользовательской статистикой.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- реализована JWT-аутентификация;
- добавлено хранение истории игр;
- создана таблица лидеров.

## Использованные инструменты

Java 18, Spring Boot, Spring Security, JWT, Spring Data JPA, PostgreSQL, Gradle.

## Полученный результат

В каталоге `src` сохранено: 39 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Настроить подключение PostgreSQL, перейти в `src/tic_tac_toe_T5` и выполнить `./gradlew bootRun`.
