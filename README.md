# Java Learning Projects

## Цель направления

Продемонстрировать навыки разработки на Java от алгоритмических задач до многослойных backend-приложений.

## Что реализовано лично

- консольные задачи на числа, массивы, строки и коллекции;
- приложение для работы с моделью питомцев;
- REST backend игры «Крестики-нолики»;
- версии backend с PostgreSQL, авторизацией, JWT и статистикой.

## Использованные инструменты

Java, Gradle Kotlin DSL, Spring Boot, Spring Data JPA, Spring Security, JWT, PostgreSQL и REST.

## Полученный результат

Подготовлена серия проектов с постепенным усложнением логики и архитектуры.

## Запуск и просмотр

Перейти в каталог выбранного проекта и выполнить команду Gradle Wrapper, указанную в его README.
