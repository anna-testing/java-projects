# Практика основ Java

## Цель проекта

Закрепить синтаксис Java и алгоритмическое мышление на серии небольших приложений.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- реализованы вычислительные задачи и обработка последовательностей;
- добавлены алгоритмы для массивов и строк;
- применены коллекции и Stream API.

## Использованные инструменты

Java 18, Gradle Kotlin DSL.

## Полученный результат

В каталоге `src` сохранено: 11 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Выбрать упражнение в каталоге `src`, перейти в его папку и выполнить `./gradlew build`; запуск main-класса доступен из IDE.
