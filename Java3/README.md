# Backend игры «Крестики-нолики»: архитектура

## Цель проекта

Разработать многослойный REST backend игры с разделением ответственности компонентов.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- реализованы доменная модель и игровая логика;
- созданы REST-контроллеры и сервисный слой;
- настроена конфигурация зависимостей Spring.

## Использованные инструменты

Java 18, Spring Boot, Gradle Kotlin DSL, REST.

## Полученный результат

В каталоге `src` сохранено: 25 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Перейти в `src/tic-tac-toe` и выполнить `./gradlew bootRun`; API станет доступен на локальном порту приложения.
