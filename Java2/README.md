# Java: учёт питомцев

## Цель проекта

Отработать ООП, коллекции, итераторы и функциональный стиль на предметной области питомцев.

## Что реализовано лично

Самостоятельно выполнена практическая часть проекта:

- создана модель питомцев с наследованием;
- реализованы расчёты питания, возраста и прогулок;
- добавлены фильтрация, группировка и пользовательский итератор.

## Использованные инструменты

Java 18, Gradle Kotlin DSL, Collections API, Stream API.

## Полученный результат

В каталоге `src` сохранено: 30 Java-файлов. Эти материалы подтверждают выполненную работу.

## Запуск и просмотр

Выбрать упражнение в каталоге `src`, перейти в его папку и выполнить `./gradlew build`; запуск main-класса доступен из IDE.
